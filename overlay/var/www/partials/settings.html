Enable Adjustable Clocks
Enable Auto Fan Control

Adjustable Clocks shows the simple global BK-B clock editor on the Miner page. When saved for the first time, it verifies the bridge-chip firmware and flashes V1 only if the chip is still stock. Disabling returns the requested clock to 400 MHz; it does not flash stock firmware.
Auto Fan uses the hottest BK-B board temperature and changes fan speed live (no sgminer restart). Configure the curve on the Miner page; the temp watchdog still handles hard over-temp cutoff.

Enable Dev Tools

Adds a Dev Tools tab with RAM/SD storage controls, a log viewer, the sgminer API console, recorder status, diagnostics export, and guarded firmware tools. It is off by default and safe to leave enabled.
